管理跨会话的长期记忆（用户级 ~/.ee/memory.md，工作区级 <项目>/.ee/memory.md）。每次新会话开始时，记忆会自动出现在上下文开头的 <MEMORY> 块里。

何时用：
- 用户明确说「记住…」「以后都…」「别再…」时，用 add 记下来（一句话，写清适用条件，如「在这个项目里用 pnpm 不用 npm」）。
- 只和当前项目有关的约定用 scope=workspace；个人偏好用 scope=user（默认）。
- 用户说「忘掉…」或记忆过时、互相矛盾时，先 list 看序号，再 remove。

何时别用：
- 一次性的任务细节、临时状态、代码里已经写明的东西。
- 密码、API key、令牌等机密：绝不写入记忆。
- 只是你自己推测出来、用户没确认过的习惯。

本会话里增删的条目从下一个新会话起才出现在 <MEMORY> 块里（为了不破坏前缀缓存），本会话内以工具结果为准。
