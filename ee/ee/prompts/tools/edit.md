在文件中做精确的字符串替换。

用法：
- 参数 edits 是数组，一次调用可改同一文件的多处；每处都对照原文件匹配，不能重叠，任一处失败则整个调用不写入。
- 编辑前必须至少用 read 读过这个文件，否则会失败。
- old_string 要逐字复制 read 输出里「行号 + 制表符」之后的原文，保持原有缩进（空格/制表符）；绝不能包含行号前缀。
- old_string 在文件中必须唯一。不唯一时会失败：请多带几行上下文让它唯一，或者确实要全部替换时设 replace_all=true（适合重命名变量）。
- 只给需要改的那一小段加上足以唯一定位的上下文，不要贴整个文件。
- 没有精确匹配时会自动容错（空白、缩进、引号/全半角）；仍失败会给出最接近的原文和行号，照它改正即可。
- 返回结果会附带 diff；改成功后不需要再 read 确认。
- 新建文件用 write。
